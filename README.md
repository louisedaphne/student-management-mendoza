## Project Description
This project is a simple Student Management Application
created using HTML, CSS, JavaScript, Node.js, and Express.js.
The application was developed and executed using
GitHub Codespaces.
## Features
- View students
- Add students
- Edit students
- Delete students
## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- GitHub
- GitHub Codespaces
## Cloud Networking
The application runs inside GitHub Codespaces.
The Node.js server listens on port 3000.
GitHub Codespaces forwards the application port so
that the web application can be accessed through
a browser.
## Cloud Security
Basic cloud security practices used in this activity include:
- No real student information was used.
- No passwords were stored in the source code.
- No API keys or credentials were committed.
- Port visibility was reviewed before sharing the application.
## Shared Responsibility Model
GitHub manages the underlying cloud infrastructure
used by GitHub Codespaces.
As the application developer, I am responsible for
the application code, repository access, credentials,
port configuration, and information stored or processed
by the application.
## Reflection Questions
### 1. What is the role of GitHub Codespaces in this activity?
The cloud that mimics the local development environment. You can develop, do a test, and execute code without having to install any dependencies on your machine.
### 2. What is the purpose of port 3000?
Port 3000 is the default listening port for most Node.js based application servers to listen to HTTP requests.
### 3. What may happen when the application port is made public?
If port is public any person with the link can have access the application. Therefore, the application must be secured because it contains private information.
### 4. Which parts of the environment are handled by GitHub
Virtual machine, servers, network, storage and the basics of security in the cloud environment is managed by the cloud provider or Github.
### 5. Which parts are your responsibility as the application developer
My responsibilities include building and maintaining the application, ensuring proper coding, handling the application’s data, passwords and other sensitive information. 
### 6. Why should passwords, API keys, and other secrets not be uploaded to a public GitHub repository?
They should never be uploaded as anyone who has access to the repository is able to obtain the credentials would allow attackers to gain access to accounts and services.
### 7. How does this activity demonstrate the Shared Responsibility Model?
 The cloud service or GitHub has the responsibility of taking care of cloud infrastructure whereas I am the one who takes care of my own application, codes, data, and security configurations.
